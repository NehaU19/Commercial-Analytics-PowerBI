# Commercial-Analytics-PowerBI

Developed an interactive Power BI dashboard to analyze import-export performance for rough and polished diamonds. The dashboard was designed to support KPI tracking, trend analysis, and business reporting for commercial decision-making.

Tools Used:
Power BI, Excel, Data Visualization, KPI Reporting

Key Features:

Import vs export performance tracking

Rough and polished diamond category analysis

Monthly trend analysis

Interactive filters and slicers

KPI monitoring dashboard

Business Insights

Identified category-wise performance trends

Improved reporting visibility through dashboard automation

Enabled quicker business analysis and decision-making through visual reporting

Note:

All sensitive business information, company identifiers, and confidential data have been anonymized for portfolio purposes.
